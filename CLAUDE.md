# NivCreative

Website project: WordPress + Elementor Pro (RTL, Hebrew), animated, visually rich. Static version in `site/`, Elementor template generated by `build_elementor.py`.

## Skills: use them without being asked
For any web design/build/animation task, load these first:
- `elementor-wp-animated-sites` (project-specific Elementor/WordPress/GSAP workflow) — always
- `frontend-design` — aesthetic direction and typography
- `emil-design-eng` — animation timing, easing, micro-interaction polish
- `ui-ux-pro-max` — palettes, font pairings, UX guidelines, GSAP presets
- `find-skills` — when a needed capability seems missing

## Conventions
- Reply to the user in Hebrew; code and comments in English.
- Edit `build_elementor.py` and regenerate `nivcreative-home-elementor.json`; don't hand-edit the JSON.
- Elementor Flexbox Containers only; RTL logical properties; respect `prefers-reduced-motion`.
- Animate `transform`/`opacity` only; keep pages working without JS.
- Commit to the assigned branch; open PRs only when asked.
