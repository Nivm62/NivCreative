## אפקטים שהועברו מבלוק הפתיחה של `/shaymentor/`
אותו קוד JS ואותם מזהים: חשיפת כותרת מילה אחר מילה (טשטוש + עלייה), הופעה מדורגת של טקסט וכפתורים, תנועת רקע לפי עכבר (ולפי גלילה במגע), זוהר שעוקב אחרי העכבר, אבק זהב ב-canvas, מעבר ברק על הבאנר, ברק זהב על מילת ההדגשה, כפתורים מגנטיים, פס התקדמות, תפריט שנעלם בגלילה וכפתור צף במובייל.
שונה בלבד: צבעים (כחול ← שחור/שמפניה), קומפוזיציה, ותמונת הרקע. כל ההנפשות מכבדות `prefers-reduced-motion`.
הקוד מתחום ל-`.syx` בתוך עמודי ה-canvas החדשים בלבד.

## תבניות Header/Footer
ה-Header וה-Footer מוטמעים בכל עמוד חדש (עמודי `elementor_canvas`), ולכן לא נוצרו או שונו תבניות Theme Builder ואין תנאי תצוגה שיכולים להשפיע על האתר הישן.

## פרסום (בוצע 1.11.2026)

3. לבדוק שליחת טופס אמיתית בכל סוג טופס.
