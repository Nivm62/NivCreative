# פרויקט שי יפרח – `/shaymentor/`

אתר מלא (15 עמודים) ב-WordPress + Elementor, כולו **טיוטה** (draft, מחוץ לאינדוקס) עד אישור פרסום.
הבנייה נעשית מהקוד כאן ונדחפת ל-WordPress דרך ה-REST API.

## מבנה
| קובץ | תפקיד |
|---|---|
| `site.css`, `extra.css` | העיצוב המאושר (נייבי + זהב, שנהב, תפריט מעוגל) + רכיבים לעמודי העומק |
| `site.js` | אנימציות עדינות (כבוד ל-`prefers-reduced-motion`), תפריט מובייל ותת-תפריטים נגישים |
| `components.py` | תפריט, פוטר, בלוקים משותפים, טפסי Elementor |
| `content.py` | התוכן של כל עמוד + מטא SEO |
| `push.py` | יצירה/עדכון של העמודים כטיוטות, הגדרות SEO (SureRank) וניקוי מטמון Elementor |
| `preview.py` | רינדור מקומי של כל העמודים לבדיקות דפדפן |
| `pages-map.json` | מזהי העמודים ב-WordPress |

הרצה: `python3 push.py` (כל העמודים) או `python3 push.py --only about contact`.

## בלוקים "בהכנה"
בבנייה לטיוטה, בלוקים שממתינים לתוכן אמיתי (עדויות, צוות) מוצגים עם מסגרת מקווקווה ותווית.
לפני פרסום: להגדיר `SHOW_PENDING = False` ב-`components.py` ולהריץ `push.py`; הבלוקים האלה ייעלמו לגמרי, בלי שום הערת עבודה באתר.

## פרסום
1. להשלים את "רשימת ההשלמות" למטה.
2. `SHOW_PENDING = False`, הרצת `push.py`.
3. להסיר `noindex` בהגדרות SureRank של כל עמוד (שדה `post_no_index`), ולפרסם.
4. לבדוק טפסים בפועל (קליטת מייל, הפניה לעמוד תודה).
