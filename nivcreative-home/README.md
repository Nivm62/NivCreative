# NivCreative – דף הבית (סטטי, עם אנימציות)

HTML + CSS + JS בלבד, בלי build. הפונט (Heebo) נטען מ-Google Fonts.

## העלאה ל-Hostinger
1. hPanel → Websites → Manage → File Manager → `public_html` (מחקו את `default.php`).
2. מעלים את `nivcreative-home.zip` ועושים Extract בתוך `public_html`. `index.html` חייב להיות ישירות ב-`public_html`.
3. ב-`index.html` מחליפים את `info@nivcreative.com` (כפתור "צור קשר עכשיו") במייל שלכם, ואת קישורי הרשתות (`href="#"` בפוטר).

אנימציות: הופעה בגלילה, ציפה, פרלקסה בעכבר על ה-NC, ספירת מספרים, תפריט מובייל. מכבדות `prefers-reduced-motion`.
